## 👨‍💻 About Me

Hello! I'm **Gabiro Jovial Fleuron**, a software developer and IT enthusiast from **Rwanda 🇷🇼**, with an academic background in Information Technology at the University of Rwanda.

I enjoy turning ideas into practical digital solutions, from web applications and backend systems to tools that address real-world challenges in healthcare, education, and employment.

My interests extend beyond application development into **Linux, networking, cloud infrastructure, cybersecurity, and system administration**. I'm interested in understanding not only how applications are built, but also how they are deployed, secured, monitored, and maintained.

* 🔭 **Building:** Web applications and practical software solutions.
* 💻 **Developing with:** JavaScript, Python, React, Node.js, and Django.
* 🌐 **Exploring:** Networking, Linux administration, cloud infrastructure, and cybersecurity.
* 🧠 **Interested in:** Technology research, system design, and social-impact innovation.
* 🤝 **Open to:** Meaningful collaborations, knowledge sharing, and opportunities to grow.
* 🎯 **Goal:** Build reliable, secure, and useful technology that solves real problems.
